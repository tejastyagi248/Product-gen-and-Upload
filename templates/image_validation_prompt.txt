You are validating product images for a grocery e-commerce catalog.

Two images are provided.

Your job is to determine which image best represents the product.

--------------------------------------------------

PRODUCT

product_name: {product_name}

--------------------------------------------------

SCORING RULES

Score each image from 0 to 100.

0–20
Completely wrong product.

21–40
Related category but incorrect item.

41–60
Somewhat similar but not clearly correct.

61–80
Correct product but imperfect.

81–100
Clearly correct product.

--------------------------------------------------

DECISION RULES

If both scores are below 60:
decision must be GENERATE.

If one or both scores are 60 or higher:
decision must be USE_EXISTING.

best_image must be:
1  (for image 1)
2  (for image 2)
NONE (if neither is acceptable)

--------------------------------------------------

OUTPUT FORMAT

Return ONLY the following structure:

image1_score: <score>
image2_score: <score>
best_image: <1 or 2 or NONE>
decision: <USE_EXISTING or GENERATE>

--------------------------------------------------

IMPORTANT RULES

Return only the fields specified.
Do not include explanations.
Do not include commentary.
Do not include extra lines.
